** Customer Relationship Management (CRM) **

A full-stack CRM application built with the MERN stack.

Status: Work in Progress --- development is ongoing.

** Tech Stack **

* React.js + Vite

* JavaScript / JSX

* CSS

* Node.js

* Express.js

* MongoDB / Mongoose

* MongoDB Atlas

* Axios

* React Router

** Project Structure **

* Customer RelationShip Management/
├── backend/
├── frontend/
├── .gitignore
└── README.md


** Current Status **

This is an active Work in Progress project.

Different modules may currently be at different stages:

* Backend development

* Postman API testing

* Frontend development

* Frontend/backend integration

* Responsive UI development

* Functional testing

The project is not yet considered fully complete.

** Development **

The project is being developed module by module according to the defined
CRM requirements. No unnecessary features or extra scope are added.

** Run Project **

* Backend:

cd backend
npm install
npm run dev

* Frontend:

cd frontend
npm install
npm run dev

The backend normally runs on http://localhost:5000.

** Git **

The root .gitignore is used to exclude files such as node_modules,
.env, and other unnecessary local files.
